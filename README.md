# 踏切くん (Fumikiri-kun)

遮断機を回して、踏切ごと進む物理アクション。
A physics action game where you spin the crossing gate arm to move the whole railroad crossing forward.

## あそぶ / Play

- Grok: https://cobalt-craft-cobalt-glow.grok.me
- GitHub Pages: https://blitast-studio.github.io/fumikiri-kun/

操作 / Controls: A / ← 左回転 (rotate left)、D / → 右回転 (rotate right)。スマホは画面下のボタン / On mobile, use the on-screen buttons.

## について / About

Grok Build (Grok App Builder) で制作し、公開中のビルドをそのまま静的サイトとして書き出したものです。
Built with Grok Build (Grok App Builder); this repository contains the deployed build exported as a static site.

ローカルで動かす / Run locally:

```sh
python3 -m http.server 8000
# → http://localhost:8000/
```
